# 小说创作助手首版实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付可在本机使用的多作品中文小说构思、写作、改写和导出流程。

**Architecture:** MySQL 保存作品、追问和候选改写；Spring Boot Service 管理阶段与版本，Controller 提供 DTO API。Vue 单页工作台按阶段调用 API；AI 调用通过配置的 OpenAI 兼容地址，密钥用 AES-GCM 加密保存。

**Tech Stack:** Java 21、Spring Boot 3.5.16、MyBatis-Plus 3.5.17、MySQL、Flyway、Vue 3、Vite 7、TypeScript 5。

**Spec:** `docs/superpowers/specs/2026-11-03-novel-assistant-design.md`

## Global Constraints

- 服务只绑定本机；无需用户认证。
- 不在日志、API 响应或 Git 中暴露密钥。
- 作品正文只在创作者明确保存或采纳候选时改变。
- 列表按更新时间降序、ID 降序排序；编辑冲突返回 409。
- AI 请求失败不修改作品；API 错误响应统一。

## Review Focus

- 空标题或空点子：创建接口返回 400，页面保留输入。
- 作品 A 的改写候选用于作品 B：拒绝采纳。
- AI 返回非预期 JSON 或空内容：返回 502，作品不变。
- 旧版本正文覆盖新版本：返回 409，页面提示刷新。
- 未设置加密主密钥时提交页面 API Key：拒绝保存并给出配置提示。
