# 本地小说创作助手｜项目计划

## 项目目标

帮助有小说点子、但希望获得文字表达和叙事支持的创作者，逐步完成中文中短篇小说。AI 与创作者共同构思、写作和修改；创作者在关键节点决定故事方向。

## 已确认的产品需求

- **使用方式**：通过在本机启动的 Web 页面使用，首版面向个人创作。
- **作品管理**：能够保存和切换多个作品，每篇作品分别保留创作材料与正文。
- **构思流程**：创作者输入点子后，AI 先追问少量影响故事走向的关键问题，再提出故事方案和大纲。
- **关键节点确认**：创作者确认或调整故事方案与大纲后，AI 再生成正文初稿。
- **写作语言与风格**：首版以中文小说为主；每篇作品可填写文风说明，供正文生成和改写参考。
- **修改方式**：创作者可选中正文片段，说明修改要求，让 AI 针对该片段提出改写；同时能够手动编辑正文。
- **导出**：支持将成稿导出为 Markdown 和纯文本。
- **AI 接入**：由创作者填写兼容 OpenAI 接口的服务地址、模型名称和 API Key；希望安全地长期保存密钥。

## 首版使用流程

1. 新建作品，记录点子和文风说明。
2. 回答 AI 提出的关键问题。
3. 阅读、调整并确认故事方案和大纲。
4. 生成正文初稿，并在页面中编辑。
5. 选中需要改善的片段，提出改写要求，审阅后决定是否采用。
6. 保存作品，按需导出 Markdown 或纯文本。

## 待讨论

- 首版验收标准和实施顺序。
